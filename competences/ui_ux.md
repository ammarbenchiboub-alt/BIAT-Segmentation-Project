# UI / UX

## Description

Conception d'une identite visuelle professionnelle adaptee a un usage bancaire interne, coherente sur l'ensemble de l'application.

## Technologies

- CSS personnalise (theming avance sur Streamlit)
- charte graphique (couleurs, typographie, composants)
- ergonomie de tableaux de donnees denses

## Fichiers

- `ui/styles.py`
- `app.py`

## Exemples concrets

- Palette et composants aux couleurs officielles BIAT (bleu/orange).
- Cartes de navigation cliquables, bandeau de marque, codes couleur semantiques (alertes).
- Coherence visuelle maintenue sur les 8 pages de l'application.

## Niveau

Redesign complet valide iterativement (retours utilisateur pris en compte).
