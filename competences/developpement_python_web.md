# Developpement Python / Web

## Description

Conception et developpement d'une application web complete en Python (Streamlit), avec une architecture modulaire en packages independants.

## Technologies

- Python 3
- Streamlit
- pandas
- programmation orientee objet

## Fichiers

- `app.py`
- `core/engine.py`
- `core/rules_loader.py`

## Exemples concrets

- Point d'entree unique (app.py) gerant navigation, sessions et 8 pages.
- Moteur de segmentation (MoteurSegmentation) en programmation orientee objet.
- Gestion d'etat via st.session_state (navigation, historique, authentification).

## Niveau

Applique dans un projet complet de bout en bout (PFE bancaire).
