# Gestion de projet

## Description

Planification et suivi d'un projet individuel selon une methodologie agile, avec un backlog priorise et un decoupage en sprints.

## Technologies

- methodologie Agile / Scrum
- backlog produit priorise (MoSCoW)
- diagramme de Gantt

## Fichiers

- `rapport/Rapport_PFE_Chapitres_1_2.docx`

## Exemples concrets

- Backlog produit avec criteres MoSCoW (BF01-BF12).
- Decoupage en 5 sprints (fevrier a juillet 2026) avec objectifs par sprint.
- Diagramme de Gantt illustrant la planification du projet.

## Niveau

Applique sur l'ensemble du cycle de vie du projet (planification -> livraison).
